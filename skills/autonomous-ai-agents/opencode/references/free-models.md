# Free models in OpenCode's built-in catalog

`opencode` exposes free-tier models under the `opencode/...-free` namespace. In this environment, `opencode/glm-5.3-flash-free` responded at **$0 cost**.

Select one with `--model opencode/<id>`:

```bash
opencode run --model opencode/glm-5.3-flash-free "Reply: OK"
```

Rebuild the catalog anytime with: `opencode models`
